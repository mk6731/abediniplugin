# abediniplugin

## منوی ال ماسو لانژ

یک صفحهٔ منوی فارسی و راست‌به‌چپ با HTML، CSS و جاوااسکریپت ساده، بدون فریم‌ورک یا نیاز به نصب است. فایل `index.html` را مستقیماً در مرورگر باز کنید. برای حفظ فونت و تصاویر محلی، پوشهٔ `assets` را کنار آن نگه دارید.

- منو شامل ۲۵ دسته و ۲۰۳ آیتم از صفحهٔ مرجع است و جست‌وجو، فیلتر دسته‌بندی و نمایش جزئیات دارد.
- متن، تصاویر و قیمت‌ها تصویری ثابت از [منوی اصلی](https://elmaso-lounge.com/menu/) در تاریخ ۲۰۲۶/۱۱/۱۱ هستند؛ قیمت‌ها به‌صورت خودکار به‌روز نمی‌شوند.
- تعدادی از عکس‌های اصلی برای بارگذاری سریع در `assets/images` قرار دارند. بقیهٔ عکس‌ها از سایت اصلی بارگذاری می‌شوند و به اینترنت نیاز دارند؛ در صورت در دسترس نبودن تصویر، جایگزین ساده‌ای نشان داده می‌شود. فونت Vazirmatn همراه مجوز آن در `assets/fonts` قرار دارد.
- بدون جاوااسکریپت نیز آیتم‌ها، توضیحات کامل و پیوندهای دسته‌ها قابل مشاهده‌اند؛ جست‌وجو و پنجرهٔ جزئیات به جاوااسکریپت نیاز دارند.

### ویرایش و بازسازی

برای تغییر محتوای منو، فایل `src/menu.txt` را ویرایش کنید. هر خط محصول شامل نام، قیمت به تومان، مسیر تصویر در سایت اصلی و توضیحات است. قالب و ظاهر در `src/template.html` قرار دارند. سپس با پایتون ۳ فایل مستقل `index.html` را مجدداً بسازید:

```bash
python3 scripts/build.py
```

اجرای آزمون‌های داده و خروجی:

```bash
python3 -m unittest discover -s tests
```
